# Office Content Search

[English](README.md)

フォルダ内の Word・Excel・PowerPoint ファイルの中身を検索し、キーワードが**どこに**あるかまで表示する VS Code 拡張機能です。

![Office ファイルを検索して結果を表示している画面](images/screenshot.gif)

## 特長

- **見つかった位置を表示** — `Sheet1 › B12`、`本文 ¶24`、`先頭ページのヘッダー`、`スライド 3 › ノート`、`グラフ "売上" › 系列名` のように、一致した箇所の位置を表示します。
- **Microsoft Office は不要** — ファイルを直接読み込むため、高速に検索でき、Office がインストールされていない環境でも使えます。
- **複数のキーワード** — スペースで区切って複数のキーワードを指定できます。語句は `"二重引用符"` で囲みます。**いずれか（OR）**／**すべて（AND）**を選べます。
- **表記ゆれに強い照合** — 大文字と小文字、全角と半角を区別しません（`ＡＢＣ` は `abc` に一致します）。
- **日付は表示どおりに検索** — Excel の日付のセルは、`2026/10/21` や `2026年10月21日` のように、Excel で表示されている文字で検索できます。
- **サイドバーの検索フォーム** — キーワード、フォルダ、ファイル種別（Excel・Word・PowerPoint）の指定を1つの画面で行えます。検索の途中でキャンセルもできます。
- **マクロ有効ファイルも安全に検索** — .xlsm、.docm、.pptm のファイルも、マクロを実行せずに検索します。
- **一致した部分を強調表示** — 結果のツリーで、一致した部分が強調表示されます。結果をクリックすると、既定のアプリでファイルが開きます。
- **ファイル名とパスのコピー** — 右クリックメニュー、または結果ビューで `Ctrl+C`／`Ctrl+Alt+C`（macOS では `Cmd`）でコピーできます。
- **結果をテキストで出力** — 結果の一覧をエディタのタブに開き、読んだり、保存したり、共有したりできます。
- **処理はローカルで完結** — すべての処理はお使いのコンピューター上で行われ、外部への送信は一切ありません。
- **日本語と英語の表示に対応**

## 検索の対象

| 形式 | 検索する内容 |
| --- | --- |
| Word (`.docx`, `.docm`) | 本文の段落と表、テキストボックス、ヘッダー・フッター、脚注、文末脚注、コメント、グラフ、SmartArt |
| Excel (`.xlsx`, `.xlsm`) | セルの値、図形とテキストボックス、グラフ（タイトル、軸ラベル、系列名）、グラフシート、SmartArt |
| Excel 97-2003 (`.xls`)） | セルの値（図形やグラフの文字は対象外） |
| PowerPoint (`.pptx`, `.pptm`) | スライドの文字と表、ノート、グラフ、SmartArt |

Excel のセルは、次の規則で照合します（`.xlsx` と `.xls` で共通です）。

- **日付**：Excel で表示されている文字で照合します（例：`2026/10/21`、`2026年10月21日`、`2026/10/21 9:30`）。
- **日付以外の数値**：表示形式に関係なく、値で照合します（`1,234` と表示されていても `1234` で照合）。

## 使い方

1. アクティビティバーの **Office 検索** のアイコンをクリックします。
2. キーワードを入力します（例：`請求書` `2026` `"プロジェクト 計画"`）。
3. **いずれか（OR）** か **すべて（AND）** を選びます。AND は「**ファイル**に全キーワードが含まれる」という条件です。同じセルや段落に含まれている必要はありません。
4. フォルダを入力するか **参照…** で選び、必要に応じて **サブフォルダを含める** をオンにします。
5. 検索する **ファイル種別（Excel・Word・PowerPoint）** を選びます。
6. 必要に応じて **結果をテキストでも出力する** をオンにします。
7. **検索** をクリックします。

エクスプローラーでフォルダを右クリックし、**このフォルダの Office ファイルを検索** を選んで検索することもできます。

検索できなかったファイルは、**スキップ** の下に理由とともに表示されます。

## 設定

| 設定 | 既定値 | 説明 |
| --- | --- | --- |
| `officeSearch.includeSubfolders` | `true` | 既定でサブフォルダも検索する |
| `officeSearch.excludeFolders` | `[".git", "node_modules"]` | サブフォルダを検索するときに除外するフォルダ名 |
| `officeSearch.maxFileSizeMB` | `50` | このサイズ（MB）を超えるファイルはスキップする |
| `officeSearch.maxHitsPerFile` | `200` | 1 ファイルあたりに表示するヒットの最大件数 |
| `officeSearch.excelShortDateFormat` | `""` | 表示形式を指定せずに入力した Excel の日付を照合する書式（例：`yyyy/m/d`）。空の場合は VS Code の表示言語で決まる |

VS Code の設定画面（`Ctrl+,`）で「Office Content Search」と検索すると、これらの設定を変更できます。

### 日付が見つからないとき

Excel で表示形式を指定せずに入力した日付（「短い日付形式」）は、**Excel を使っている PC の地域設定**によって表示が変わります。ファイルには表示の書式が保存されていないため、この拡張機能では次のように書式を決めています。

- `officeSearch.excelShortDateFormat` が設定されていれば、その書式
- 空の場合は、VS Code の表示言語が日本語なら `yyyy/m/d`、それ以外なら `m/d/yyyy`

**VS Code を英語で使っていて、Excel は日本語の環境で使っている場合**は、日付が `10/21/2026` の形で照合されるため、`2026/10/21` では見つかりません。その場合は、設定に `yyyy/m/d` を指定してください。

```json
"officeSearch.excelShortDateFormat": "yyyy/m/d"
```

## 制限事項

- 旧形式の Word と PowerPoint（`.doc`、`.ppt`）には対応していません。これらのファイルは「スキップ」に表示されます。
- `.xls` で検索できるのはセルの値だけです。図形やグラフの文字は検索されません。
- パスワード付きのファイルや、暗号化されたファイル（秘密度ラベルで保護されたファイルを含む）はスキップされます。
- 検索の対象になるのは、保存されている内容だけです。Office で編集した内容は、保存してから検索してください。
- 和暦（令和など）で表示している日付は、西暦で照合されます（例：`令和8年10月21日` は `2026年10月21日` として照合）。
- Excel の数式そのものは検索の対象外です（計算結果のみが対象です）。
- Word の文字は段落ごとに照合します。2 つの段落にまたがる語句は見つかりません。
- 変更履歴で削除された文字は、検索の対象外です。
- 結果をクリックすると、ファイルの種類に関連付けられたアプリでファイルが開きます。WSL では、Windows 側のアプリで開きます。その他のリモート環境（SSH、Dev Containers）では、ファイルが開かない場合があります。

## 動作環境

VS Code 1.85 以降  
  
結果からファイルを開く機能は、Windows と WSL で動作を確認しています。
